THE IDEA BEHIND THE RESEARCH

從辨識疾病，到兼顧公平。

以兩階段學習建立表徵與分類能力，
再透過群體評估，看見模型表現的全貌。

01 / REPRESENT

學習病理表徵

從病理影像圖塊中提取視覺特徵，
讓模型聚焦與診斷相關的訊號。

02 / CONTRAST

減少群體偏差

導入公平性感知對比學習，
兼顧疾病辨別與人口群體公平性。

03 / EVALUATE

看見效能全貌

同時比較預測效能與群體差距，
避免平均數掩蓋弱勢群體的表現。

方法概念

  1. 病理影像處理：將全玻片影像切割為圖塊，以供視覺表徵學習。
  2. 公平性感知表徵：透過對比學習，學習兼顧疾病辨別與群體公平性的特徵。
  3. 下游分類：使用表徵進行任務微調。
  4. 群體評估：比較各人口群體的效能，搭配統計分析評估差異。

此為原研究的高階概念，展示程式只實作第 4 步的彙總結果呈現，沒有執行原研究的訓練、推論或統計檢定。

成果來源與解讀

來源為 hms-dbmi/fairpath README，查核日期為 2026-11-17。其摘要列出 20 種癌症、88.5% 觀察差異緩解、15 個獨立驗證世代與 91.1% 外部差距縮減。數值屬原作者研究成果，本展示未重現該實驗。

使用者提供的「驗證部署報告」作為展示主題與架構參考；報告中的詳細架構、環境版本、樣本數和統計檢定描述未作為本展示已完成的驗證聲明。原研究 README 未分發預訓練權重。

本面板的 EOpp / EBAcc 使用群體間最大與最小值之差；不宣稱完全重現原研究統計流程。群體 AUROC 平均無法代替 pooled AUROC；p ≥ 0.05 亦不能單獨證明群體等效或完全公平。

使用限制

本工具供研究溝通與成果展示，非臨床診斷工具。合成數據不代表真實癌種、醫院或人口群體。匯入數據由提供者負責來源、授權與正確性，介面不會自動認證為真實研究成果。
