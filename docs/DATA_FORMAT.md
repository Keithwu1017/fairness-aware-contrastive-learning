# 彙總資料格式

使用 UTF-8 CSV。可直接下載介面中的合成資料範例並依格式替換。

| 欄位 | 說明 |
| --- | --- |
| scenario | 評估情境，例如已去識別化的資料集名稱，1–80 字元 |
| model | 固定為 Baseline 或 Fairness-aware |
| group | 去識別化群體標籤，1–80 字元 |
| auroc | 該群體 AUROC，0–1 |
| tpr | 該群體 True Positive Rate / Recall，0–1 |
| tnr | 該群體 True Negative Rate / Specificity，0–1 |
| n | 該群體樣本數，正整數 |

每個情境須同時包含兩模型，具有相同的 2–12 個群體，同群體 n 相同，且每個情境／模型／群體只能有一列。最多 1 MB、1000 列。額外欄位不會顯示或用於計算。

請確保兩模型使用同一測試群體、標籤、評估切分與相容的決策閾值；格式檢查無法驗證這些研究條件。多折結果應先以適當方法彙總，不可將同群體各折當成不同群體。缺失指標不會以 0 代替，整份資料會被拒絕。

EOpp gap = max(TPR) − min(TPR)。EBAcc gap = max((TPR+TNR)/2) − min((TPR+TNR)/2)。群體 AUROC 平均為未加權算術平均。n 用於完整性檢查及表格呈現，不用於近似 pooled AUROC。

只提供已獲授權、可公開展示的彙總結果；勿上傳病患姓名、識別碼或個別病例。匯入來源一律標示「使用者匯入彙總數據（未經本專案驗證）」。應用程式不會將上傳檔案提交到 GitHub；Gradio 會在主機建立暫存上傳檔案，管理者需依部署環境管理暫存與存取。
